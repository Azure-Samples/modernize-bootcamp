Modernize with confidence Bootcamp 

During this bootcamp, your team will assess, migrate, modernize, and optimize existing on-premises applications hosted on Windows Server 2016 and Microsoft SQL Server 2016 as they move to Microsoft Azure in a secure way. By working through this bootcamp your team will gain the knowledge necessary to perform migrations\modernization of applications and VMs that use legacy Windows operating systems to Azure, modernize applications by transitioning from on- prem to IaaS to PaaS, Saas services, and begin to gain insights into application performance and behaviors and how to secure organizational secrets. 

Any resemblance to actual scenarios, issues, or pain points that you are facing is *not* purely coincidental. The definitions of the challenges that will be presented to you during this event are inspired by real life. 

Caldova Mortgage – Azure Modernization Initiative 

Caldova Mortgage company is a leading mortgage lender and loan-servicing organization that has expanded through both organic growth and strategic acquisitions. As the business evolved, its technology landscape became increasingly complex, resulting in a large and diverse application portfolio spanning loan origination, servicing, compliance, customer engagement, and business operations. 

Today, Caldova Mortgage is embarking on a strategic digital transformation initiative to modernize its technology estate and accelerate innovation using Microsoft Azure. The organization's legacy datacenter environment consists of more than 500 servers supporting business-critical applications, databases, and integration services. These environments are managed by a lean IT operations team that faces growing challenges related to scalability, security, resiliency, and operational efficiency. 

A recent technology assessment identified several opportunities for modernization. Many applications continue to run on aging infrastructure and legacy operating systems, creating technical debt and limiting the organization's ability to respond to changing business demands. In addition, some applications have complex interdependencies, limited documentation, and are hosted on virtualized environments that require significant operational oversight. These factors increase operational risk and constrain Caldova Mortgage's ability to adopt modern development practices and deliver new business capabilities rapidly. 

To address these challenges, Caldova Mortgage has partnered with Microsoft to define and execute a comprehensive Azure modernization strategy. The organization already maintains an Enterprise Agreement and views Azure as the strategic platform for future growth. Rather than simply relocating workloads (from on-premises VMs to Azure VMs), Caldova Mortgage aims to modernize its applications, data platforms, and operational processes to take advantage of cloud-native capabilities. 

 

Migrating infrastructure and virtual machines to Azure using Azure Migrate. 

Modernizing application hosting through Azure App Service, Azure Container Apps, and Azure Kubernetes Service (AKS). 

Transforming legacy databases into Azure SQL Managed Instance, Azure SQL  Database. 

Implementing modern identity, security, and governance using Microsoft Entra ID, Azure Policy, Defender for Cloud, and Azure Key Vault. 

Establishing DevSecOps practices using GitHub, GitHub Copilot, GitHub Actions, and Azure DevOps. 

Improving observability and operational excellence through Azure Monitor, Application Insights, and automated remediation capabilities. 

Leveraging GitHub Copilot modernization extension to assess application code, identify upgrade and modernization opportunities, and assist with recommended code changes. 

Optimizing cloud spend through FinOps practices and Azure Cost Management. 

While cloud adoption represents a significant opportunity, Caldova Mortgage recognizes that many applications have evolved over decades and that source code may be unavailable or difficult to modify. As a result, the organization is adopting a phased modernization approach that balances business continuity with innovation. Workloads will be evaluated using the Azure migration and modernization framework to determine the most appropriate strategy, including rehost, replatform, refactor, rearchitect, rebuild, or retire. 

As an initial step, IT leadership has selected a representative set of production workloads that reflect the diversity and complexity of the broader application portfolio. These workloads will serve as pilot candidates for assessment, dependency analysis, migration testing, modernization validation, and operational readiness activities. Lessons learned from these pilot implementations will establish repeatable patterns and best practices for scaling modernization efforts across the remainder of the enterprise estate. 

The expected outcomes of this initiative include improved business agility, enhanced security and compliance, increased application resiliency, reduced technical debt, accelerated delivery of customer-facing innovations, and a scalable cloud foundation capable of supporting Caldova Mortgage's future growth. 

 

Caldova Mortgage currently relies on two business-critical web applications to support its mortgage operations. The first application, **Caldova Mortgage**, is a public-facing customer portal where users can submit mortgage requests, check application status, and access information about available mortgage products and services. The second application, **Caldova Mortgage Admin**, is an internal employee-facing portal used by loan officers and operations teams to review, process, and manage mortgage applications. 

 

As part of the Azure modernization initiative, these applications must be migrated\modernized and evolved with minimal disruption to customers, employees, and business operations. The initial priority is to establish a secure, reliable Azure foundation that can support the existing application workloads while reducing dependency on aging on-premises infrastructure. Where appropriate, the team will evaluate opportunities to move beyond traditional Infrastructure-as-a-Service hosting and adopt Azure platform and native services that improve scalability, resiliency, security, observability, and operational efficiency. 

 

**Your mission is to modernize the existing applications and databases to Azure. This includes validating migration readiness, preserving application functionality, minimizing downtime, and identifying where components can be rehosted, replatformed, refactored, or transitioned to managed Azure services over time.** 

 

The success of the initiative depends on the team’s ability to execute a low-risk modernization, maintain business continuity, and establish repeatable modernization patterns that can be applied across the broader Caldova Mortgage application portfolio. 

 

### On-premises architecture 

 

Caldova Mortgage currently hosts **Caldova Mortgage** and **Caldova Mortgage Admin** on various versions of Windows Server in virtual machines on Hyper-V. The virtual machines are on a single host. Each application consists of a web tier, an application (API) tier, and a shared data tier utilized by both the public-facing and employee-facing sites. Except for the shared data tier, each application tier resides on its own virtual machine. 

 

The application tiers are segmented and constrained in communication through Windows Firewall. The web front ends are accessible over port 80 and 8080 to end-users and are not using SSL currently. The application tier is only accessible over port 2901 by the respective application server, and the database tier is only accessible over port 1433. 

 

The public-facing application, **Caldova Mortgage** (or **CM**), is an ASP.NET MVC web application with a Microsoft SQL Server backend that leverages forms-based authentication (FBA) for customer logins. The internal application, **Caldova Mortgage Admin** (or **CMA**), is also an ASP.NET MVC web application with a Microsoft SQL Server backend. **CMA** leverages integrated Windows authentication (IWA) to allow employees to access the site.
