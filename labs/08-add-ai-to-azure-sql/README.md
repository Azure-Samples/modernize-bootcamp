# 🧠 Lab 08: Add AI to Azure SQL

> 🚧 **Placeholder.** This module is not written yet. The outline below is the intended shape, not final content.

Module 05 moved the `eShop` database to Azure SQL. That move did more than change where the data lives — it put the catalog on a platform that can do work the old SQL Server instance could not.

This module uses that capability. Rather than bolting a separate AI service onto the application, the intelligence goes where the data already is.

## 📋 What you'll do

- Explore the AI capabilities Azure SQL offers over the migrated catalog
- Add semantic search across products, grounded in the real data
- Surface the result in the modernized storefront
- Weigh doing this in the database against calling an external service
